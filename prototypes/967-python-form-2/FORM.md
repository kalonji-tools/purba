# The rules of this form

A prototype test form, run by its own small runner: `python run.py [file or folder …]`. The tester imports `experiment`, `use` and `handling` from `experiment.py`.

- **An experiment is a function under `@experiment`: its parameters are the inputs, its body is the act.** The act is a straight line of statements: any calls, in order, with literals and nested calls. It holds no `if`, loop, comprehension, `try`, `with`, `assert`, `raise`, lambda or nested `def`/`class`. What it returns is the product; with no `return`, the product is `None`.
- **A case is a call of the experiment, named by its variable:** `plain = slug_of(text="Hello World").expect(product="hello-world")`. A type checker reads the call against the act's parameters, so it sees a misspelled input, an input of the wrong type, and a `product` of the wrong type. Each input is named; a parameter with a default may be left out.
- **`.expect(product=…, <assay>=…)`** names the expected values: `product` is what the act returns, and each other name is an assay. Each expected value is a literal, or a name bound to one. `.raises(Type, match=r"…")` expects a raise whose message `re.search` finds; `.warns(Type, match=r"…")` expects a warning. A warning that the case does not expect fails the case.
- **An assay is a function under `@<experiment>.assay`** that takes one parameter, `product` or one input by its name, and is one `return` of what it reads. Its name is the question the failure screen prints; its docstring, if it has one, is printed under a failure. An assay that reads an input reads it after the act ran.
- **A fixture is a default of the act, `use(factory)`:** `writer: Writer = use(Writer)`. The runner calls `factory()` again for each case. A case may pass its own value instead.
- **Code that must run inside an `except`** is a call of `handling(exception, function, *args)`: it raises `exception` and calls `function(*args)` while handling it.
- **A process of several stages is one act,** with one statement for each call. When a later case must start from what an earlier case made, it takes `earlier.product` as an input. The runner then runs the earlier case again first, once, and blocks the later case if the earlier one reads differently.
- **Each case runs in a forked process of its own,** and each assay but the last in a fork of its own, so nothing a case does reaches another. Output a case prints is shown only when it fails.
- **A reading is compared by type, then by value.** A reading must be an instance of the expected value's type (a subclass of `str` is a `str`), except that `True` is never `1` and `1.0` is never `1`. Lists, tuples and dicts are compared item by item.
- **The runner refuses, before the run:** a misspelled input or assay (with a hint), an expected value that is computed or does not fit its assay's return type, a case that checks nothing, a case with no name, a case name bound twice, cases built by a loop, and logic in an act or an assay. A refusal of a case stops only that case; a refusal of an experiment (its act or an assay) stops its cases.
- **The run ends with a count,** `N cases: … passed · … failed · … refused · … blocked`, and exits 1 unless every case passed.
